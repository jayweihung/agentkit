# 在 Herdr 裡用 kit

不想打指令的話，kit 在 Herdr 裡有三個地方可以用：

| 在哪裡 | 做什麼 |
|---|---|
| 每個 agent 視窗上面的 **kit 按鈕** | 看這個 agent 在用哪些規則、skill、MCP，加上或拿掉 |
| 右上角的 **kit 面板（倉庫）** | 看、改、新增規則、skill、MCP，改好按「送出」 |
| 倉庫上面的 **Agents 按鈕** | 管 kit 做好的 agent（用哪些東西），用 Claude、Codex 或 omp 開起來 |

Windows、Mac、Linux 都一樣。

## 安裝

    kit herdr-panel install       裝進 Herdr
    kit herdr-panel uninstall     拿掉，Herdr 回到原本的樣子

裝的時候會：

- 在上排分頁列加一顆 `kit` 按鈕，按了開關右邊的倉庫面板。
- 把每個窗格的標題列換成有 kit 按鈕的版本（拿掉時換回 Herdr 原本的）。
- 在 Herdr 的 `mods/` 放 `kit`、`kit-pane`、`kit-agents` 三個資料夾。

改版面前會留一份 `layouts/<版面>.json.kit-backup-<時間>`。
Herdr 內建的版面（main 等）不能改：面板會先出現在右邊，按面板上的「放進上排」會複製一份版面再放進去。
`kit self-update` 之後，裝好的面板會自動換成新版。

## 1. agent 視窗上的 kit 按鈕

每個 agent（Claude Code、Codex、omp）視窗的標題列右邊有一顆按鈕，寫著它在用幾個東西：

```
┌──────────────────────────────────────────────────────────────────────┐
│ ■ Claude Code   ~/src/myproj        [kit  規則 2  skill 3  MCP 1]  ○ │
├──────────────────────────────────────────────────────────────────────┤
│ >                                                                    │
```

按下去會跳出這個 agent 的清單：

```
┌──────────────────────────────────────────┐
│ ■ Claude Code              ⟳ 同步    ✕  │
│   這台電腦 · ~/src/myproj                │
├──────────────────────────────────────────┤
│ 這個 agent 在用的                        │
│ ▾ 規則（2）                              │
│   zh-tw        [kit · 必備]      拿不掉  │
│   CLAUDE.md    [這個目錄]                │
│ ▾ Skills（3）                            │
│   kit-hello    [kit]             [拿掉]  │
│   ...                                    │
│ ──────────────────────────────────────── │
│ ▾ 可以加上的（5）                        │
│   humanizer                      [加上]  │
└──────────────────────────────────────────┘
```

- 標 `kit` 的是 kit 管的，可以「拿掉」；標 `kit · 必備` 的是團隊規定要有的，拿不掉。
- 標 `這個目錄`、`這個帳號` 的是 agent 自己從資料夾讀到的（`CLAUDE.md`、`.claude/rules`、`.claude/skills`、`.mcp.json`），只顯示，不改。
- **注意**：這裡的「加上」「拿掉」是整個帳號的，這台電腦上你帳號的每個 agent 都會一起有或一起沒有。
- agent 開在別台主機（Herdr 的遠端 space）時，按鈕會到那台去問 kit。那台要裝好 kit。
- 用別的帳號跑的 agent（例如 `sudo -i` 的 root）只會顯示「root 唯讀」，這裡看不到也不能改。
- 新加的 MCP 要重開 agent 才會讀到。

按鈕上的字：`…` 還在讀；`出錯了` 點開看原因（常見的是那台沒裝 kit）。

## 2. 倉庫：看、改、新增

上排的 `kit` 按鈕開關右邊的倉庫。這裡列出來源裡所有的規則、skill、MCP，可以直接改內容。
改的是這台電腦上來源的檔案，送出後，每台主機 `kit sync` 就會拿到（不用管是哪台主機）。

```
┌──────────────────────────────────────────┐
│ kit  倉庫                 [送出] Agents ⟳ ✕ │
│      改過 1 個檔案，還沒送出             │
├──────────────────────────────────────────┤
│ [規則 5] Skills 2  MCP 1        [＋ 新增] │
│ ┌──────────────────────────────────────┐ │
│ │ 找：名字、說明、來源                 │ │
│ └──────────────────────────────────────┘ │
│ chrome-reconnect  [改過]               › │
│   my-team-source                         │
│ zh-tw  [團隊必備]                      › │
│   my-team-source                         │
└──────────────────────────────────────────┘
```

點一列就打開它：

```
┌──────────────────────────────────────────┐
│ [← 回去]  chrome-reconnect  [⤢ 放大][存檔] │
│           my-team-source · rules/chrome-reconnect.md │
├──────────────────────────────────────────┤
│ 1  # Chrome 連不上                       │
│ 2                                        │
│ 3  ...                                   │
├──────────────────────────────────────────┤
│ 還沒存檔            [重新讀取][用編輯器開] │
└──────────────────────────────────────────┘
```

- **存檔**：寫回檔案。如果檔案在別的地方被改過，會擋下來，不會蓋掉別人的；先複製你改的，按「重新讀取」，再貼回去。
- **⤢ 放大**：用大視窗改，還沒存的內容會一起帶過去。大視窗可以拖，按「✕ 關掉」。
- **用編輯器開**：用這台電腦平常的編輯器打開（Mac 是文字編輯、Windows 是預設程式、Linux 是 `xdg-open`）。
- **＋ 新增**：打名字（小寫英文、數字和 `-`），選放在哪個來源，按「建立」。kit 會建好起始檔案並打開它（就是 `kit new`）。
- **送出**：有改過的檔案時才會出現。先跑 `kit check`，有問題就什麼都不送。過了才 `kit push`：
  - 來源有 `origin`（團隊放在 Gitea 的）：開一個 `kit/...` 分支、push、開 PR，等別人審。
  - 來源沒有 `origin`（自己的）：直接 commit 到現在的分支，推到它所有的 remote，不開 PR。
- 想先看會送什麼：在終端機打 `kit push --to <來源名字> --dry-run`。

## 3. Agents：做好的 agent

倉庫上面的 `Agents` 按鈕開關 Agents 視窗。這裡是來源裡 `agents/` 的 agent，每個是一組挑好的規則、skill、MCP 加上提示。

```
┌──────────────────────────────────────────┐
│ agent  Agents                       ⟳ ✕ │
│        2 個 agent · 用 kit run 開        │
├──────────────────────────────────────────┤
│ hello                                  › │
│   測試用 agent · my-team-source          │
│   規則 1 · skill 1 · MCP 0               │
│ ping   [改過]                          › │
│   ...                                    │
└──────────────────────────────────────────┘
```

點一個 agent：

- 看它用了哪些規則、skill、MCP，「拿掉」或從「加上…」裡加（就是 `kit agent <名字> add|rm ...`，改的是來源裡的 agent 檔）。
- 改完一樣回倉庫按「送出」。
- 選 Claude、Codex 或 omp，按「開啟」，會在新分頁用 `kit run <名字> --tool ...` 開起來。這只影響這次開的 agent，不改你的設定檔。
- 「編輯檔案」可以直接改 agent 檔（提示、說明）。

## 指令對照

| 畫面上 | 等於打 |
|---|---|
| 視窗按鈕的清單 | `kit list --json --dir <資料夾> --pid <行程>` |
| 加上／拿掉（視窗按鈕） | `kit add` ／ `kit rm` |
| ⟳ 同步 | `kit sync` |
| 倉庫的清單 | `kit list --json` |
| ＋ 新增 | `kit new <種類> <名字> --to <來源>` |
| 送出 | `kit push --to <來源>` |
| Agents 清單 | `kit agents --json` |
| agent 的加上／拿掉 | `kit agent <名字> add|rm <種類> <東西>` |
| 開啟 | `kit run <名字> --tool <工具>` |
