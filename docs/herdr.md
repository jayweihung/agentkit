# 在 Herdr 裡用 kit

不想打指令的話，kit 在 Herdr 裡有三個地方可以用：

| 在哪裡 | 做什麼 |
|---|---|
| 每個 agent 視窗上面的 **Kit 按鈕** | 看這個 agent 在用哪些規則、skill、MCP，加上或拿掉 |
| 上排的 **Kit** 按鈕 → 倉庫 | 看、改、新增規則、skill、MCP，改好按「送出…」 |
| 上排的 **Agents** 按鈕 → Agents | 管 kit 做好的 agent（用哪些東西），用 Claude、Codex 或 omp 開起來 |

上排長這樣（Kit 和 Agents 各開各的面板，可以只開一個，也可以兩個一起開）：

```
┌─────────────────────────────────────────────────────────────────────┐
│ [分頁1] [分頁2] +                                     Agents · Kit │
└─────────────────────────────────────────────────────────────────────┘
```

Windows（和 Linux）的分頁列自己畫最小化、最大化、關閉，所以 `Agents`、`Kit` 放在分頁列的左邊，關閉鈕留在最右上角：

```
┌─────────────────────────────────────────────────────────────────────┐
│ Agents · Kit │ [分頁1] [分頁2] +                          ─  □  ✕ │
└─────────────────────────────────────────────────────────────────────┘
```

Windows、Mac、Linux 都一樣。

## 安裝

    kit herdr-panel install       裝進 Herdr
    kit herdr-panel uninstall     拿掉，Herdr 回到原本的樣子

裝的時候會：

- 在上排分頁列加 `Agents` 和 `Kit` 兩顆按鈕，各自開關右邊的 Agents 面板和倉庫面板（剛裝好時倉庫是打開的，Agents 收著）。
- 把每個窗格的標題列換成有 Kit 按鈕的版本（拿掉時換回 Herdr 原本的）。
- 在 Herdr 的 `mods/` 放 `kit`、`kit-pane`、`kit-agents` 三個資料夾。

改版面前會留一份 `layouts/<版面>.json.kit-backup-<時間>`。
Herdr 內建的版面（main 等）不能改：面板會先出現在右邊，按面板上的「放進上排」會複製一份版面（叫 `main-kit`），把兩顆按鈕和兩個面板放進去。
分頁列如果是放在直排裡（內建的 main 就是），kit 會先在它外面包一個橫排（`kit-tabs-row`），按鈕才會在同一排；拿掉 kit 時會還原。
上排已經有自己的按鈕（例如 Git）的話，可以自己改版面的 JSON 調順序，kit 的節點是 `kit-agents-toggle`、`kit-toggle`、`kit-panel`、`kit-agents-panel`。
`kit self-update` 之後，裝好的面板會自動換成新版。

## 1. agent 視窗上的 Kit 按鈕

每個 agent（Claude Code、Codex、omp）視窗的標題列右邊有一顆按鈕，寫著它在用幾個東西：

```
┌──────────────────────────────────────────────────────────────────────┐
│ ■ Claude Code   ~/src/myproj        [Kit  規則 2  skill 3  MCP 1]  ○ │
├──────────────────────────────────────────────────────────────────────┤
│ >                                                                    │
```

按下去會跳出這個 agent 的清單：

```
┌──────────────────────────────────────────┐
│ ■ Claude Code              [同步] ⟳  ✕  │
│   這台電腦 · ~/src/myproj                │
├──────────────────────────────────────────┤
│ 這次啟動帶的（agent hello）              │  ← 只有用 kit run 開的才有
│   kit-hello                              │
│ 這個 agent 在用的                        │
│ ▾ 規則（2）                              │
│   zh-tw     [Kit · 團隊必備]     拿不掉  │
│   CLAUDE.md    [這個資料夾]              │
│ ▾ Skills（3）                            │
│   my-skill  [Kit · 整個帳號] [從帳號拿掉]│
│   ...                                    │
│ ──────────────────────────────────────── │
│ ▾ 可以加到整個帳號的（5）                │
│   humanizer              [加到整個帳號]  │
└──────────────────────────────────────────┘
```

- 標 `Kit · 整個帳號` 的是 kit 裝的，可以「從帳號拿掉」；標 `Kit · 團隊必備` 的是團隊規定要有的，拿不掉。
- 標 `這個資料夾`、`這個帳號（不是 kit 的）` 的是 agent 自己讀到的（`CLAUDE.md`、`.claude/rules`、`.claude/skills`、`.mcp.json`），只顯示，不改。
- **注意**：「加到整個帳號」「從帳號拿掉」改的是整個帳號，這台電腦上你帳號的每個 agent 都會一起有或一起沒有。
- 「這次啟動帶的」：用 `kit run`（或 Agents 的「開啟」）開的 agent 才有，只有這個 agent 有，關掉就沒了。要改，到 Agents 改那個 agent。這時下面的標題會變成「另外也讀到的」。
- `同步` = `kit sync`（拿來源的新版、裝上團隊必備的）；`⟳` 只是重新讀一次畫面，不改任何東西。
- agent 開在別台主機（Herdr 的遠端 space）時，按鈕會到那台去問 kit。**每台要跑 agent 的主機都要裝好 kit**（`kit init` 過），不然會顯示「出錯了」。
- 用別的帳號跑的 agent（例如 `sudo -i` 的 root）只會顯示「root 唯讀」，這裡看不到也不能改。
- 新加的 MCP 要重開 agent 才會讀到。

按鈕上的字：`…` 還在讀；`出錯了` 點開看原因（常見的是那台沒裝 kit）。

## 2. 倉庫：看、改、新增

上排的 `Kit` 按鈕開關右邊的倉庫。這裡列出來源裡所有的規則、skill、MCP，可以直接改內容。
改的是這台電腦上來源的檔案，送出後，每台主機 `kit sync` 就會拿到（不用管是哪台主機）。

```
┌──────────────────────────────────────────────────┐
│ Kit  倉庫                     [送出…] [同步] ⟳ ✕ │
│      改過規則／skill／MCP 1 個檔案，還沒送出     │
│ [my-team-source 團隊 · 送出要審]                 │
├──────────────────────────────────────────────────┤
│ [規則 5] Skills 2  MCP 1               [＋ 新增] │
│ ┌──────────────────────────────────────────────┐ │
│ │ 找：名字、說明、來源                         │ │
│ └──────────────────────────────────────────────┘ │
│ chrome-reconnect  [改過]                       › │
│   my-team-source                                 │
│ zh-tw  [團隊必備]                              › │
│   my-team-source                                 │
└──────────────────────────────────────────────────┘ │
│ chrome-reconnect  [改過]               › │
│   my-team-source                         │
│ zh-tw  [團隊必備]                      › │
│   my-team-source                         │
└──────────────────────────────────────────┘
```

點一列就打開它：

```
┌──────────────────────────────────────────┐
│ [← 回去]  chrome-reconnect  [⤢ 放大][存檔] │
│           my-team-source · rules/chrome-reconnect.md │
├──────────────────────────────────────────┤
│ 1  # Chrome 連不上                       │
│ 2                                        │
│ 3  ...                                   │
├──────────────────────────────────────────┤
│ 還沒存檔            [重新讀取][用編輯器開] │
└──────────────────────────────────────────┘
```

- **存檔**：寫回檔案。如果檔案在別的地方被改過，會擋下來，不會蓋掉別人的；先複製你改的，按「重新讀取」，再貼回去。
- **⤢ 放大**：用大視窗改，還沒存的內容會一起帶過去。大視窗可以拖，按「✕ 關掉」。
- **用編輯器開**：用這台電腦平常的編輯器打開（Mac 是文字編輯、Windows 是預設程式、Linux 是 `xdg-open`）。
- **＋ 新增 → 自己從頭寫**：打名字（小寫英文、數字和 `-`），選放在哪個倉，按「建立並打開」。
  框裡會寫出檔案會建在哪裡，例如 `~/src/agentkit-home/skills/my-review/SKILL.md`。kit 建好起始檔案後就在面板打開它（就是 `kit new`）。
  寫完：存檔 → 上排「送出…」送上去 → 要用它就到 Agents 視窗按「加到整個帳號」。
- **＋ 新增 → 從網址收別人的**（只有 Skills 分頁有）：貼上別人的 repo 網址，選放在哪個倉，按「下載看看」。
  這一步只看不放：列出 repo 裡找到的 skill（有好幾個就讓你選）、授權、會執行的程式、會放到哪裡。
  沒問題就按「收進來」（就是 `kit collect`）。收的是文字檔加原作者的 LICENSE，並記在倉裡的 `third_party.lock`。
  作者還不在倉的允許清單（`kit.yaml` 的 `collect_sources`）時：
  - 你自己的倉（`push: direct`）：按鈕變成「加進清單並收進來」，會一起把作者加進清單。
  - 團隊的倉：不能收，要請維護者把作者加進清單。
  收進來後跟其他改動一樣：用 `git diff` 看檔案 → 「送出…」→ 「加到整個帳號」。

```
┌ 新增 skill ──────────────────────────────────┐
│ [自己從頭寫] [從網址收別人的]                │
│ 網址（GitHub 之類的 repo）                   │
│ [https://github.com/作者/repo         ]      │
│ 放在哪個倉                                   │
│ [agentkit-home（自己的 · 直接推）]           │
│ [agentkit-library（自己的 · 直接推）]        │
│ [重新下載] 取消                              │
│ ┌──────────────────────────────────────────┐ │
│ │ archify  archify/     [加進清單並收進來] │ │
│ │ Create validated architecture, …         │ │
│ │ 授權：Apache-2.0                         │ │
│ │ ⚠ 有 103 個會執行的程式，送出前請看過    │ │
│ │ 會放到 ~/src/agentkit-library/skills/…   │ │
│ │ 還不在允許清單：按下去會一起加進去       │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```
- **送出…**：有改過的檔案時才會出現。按了先列出每個來源會送哪些檔案（`kit push --dry-run`），確認後按那個來源的「確定送出」。
  送出前會跑 `kit check`，有問題就什麼都不送。送的方式看來源的 `kit.yaml`：
  - `push: pr`（不寫就是這個，標「團隊 · 送出要審」）：開一個 `kit/...` 分支、push 到 `origin`、開 PR，等別人審。
  - `push: direct`（標「自己的 · 直接推」）：直接 commit 到現在的分支，推到它所有的 remote，不開 PR。
    本機比遠端舊或有還沒推的 commit 時會擋下來，不會亂推。
- **同步**：`kit sync`。**⟳**：重新讀取畫面。
- 想在終端機先看會送什麼：`kit push --to <來源名字> --dry-run`。

```
┌──────────────────────────────────────────┐
│ 送出前看一下                      [取消] │
│ my-team-source   團隊 · 送出要審 [確定送出]│
│   skills/my-skill/SKILL.md               │
│ agentkit-home    自己的 · 直接推 [確定送出]│
│   rules/zh-tw.md                         │
└──────────────────────────────────────────┘
```

## 3. Agents：做好的 agent

上排的 `Agents` 按鈕開關右邊的 Agents 面板（和倉庫一樣是獨立的面板，不在倉庫裡面）。
有改過還沒送出的 agent 時，按鈕旁邊會有一個小點。
這裡是來源裡 `agents/` 的 agent，每個是一組挑好的規則、skill、MCP 加上提示。

```
┌──────────────────────────────────────────┐
│ Agents                              ⟳ ✕ │
│        2 個 agent · 用 kit run 開        │
├──────────────────────────────────────────┤
│ hello                                  › │
│   測試用 agent · my-team-source          │
│   規則 1 · skill 1 · MCP 0               │
│ ping   [改過]                          › │
│   ...                                    │
└──────────────────────────────────────────┘
```

點一個 agent：

- 看它用了哪些規則、skill、MCP，「拿掉」或從「加上…」裡加（就是 `kit agent <名字> add|rm ...`，改的是來源裡的 agent 檔）。
- 改完一樣回倉庫按「送出…」。
- 選 Claude、Codex 或 omp，按「開啟」，會在新分頁用 `kit run <名字> --tool ...` 開起來。這只影響這次開的 agent，不改你的設定檔。
- 「編輯檔案」可以直接改 agent 檔（提示、說明）。

## 指令對照

| 畫面上 | 等於打 |
|---|---|
| 視窗按鈕的清單 | `kit list --json --dir <資料夾> --pid <行程>` |
| 加到整個帳號／從帳號拿掉 | `kit add` ／ `kit rm` |
| 同步 | `kit sync` |
| ⟳ | 只重新讀取畫面 |
| 倉庫的清單 | `kit list --json` |
| ＋ 新增 → 自己從頭寫 | `kit new <種類> <名字> --to <來源>` |
| ＋ 新增 → 從網址收：下載看看 | `kit collect <網址> --to <來源> --look`（只看，輸出 JSON） |
| ＋ 新增 → 從網址收：收進來 | `kit collect <網址> --to <來源> --path <資料夾> [--allow]` |
| 送出 → 確定送出 | `kit push --to <來源> --dry-run` → `kit push --to <來源>` |
| Agents 清單 | `kit agents --json` |
| agent 的加上／拿掉 | `kit agent <名字> add|rm <種類> <東西>` |
| 開啟 | `kit run <名字> --tool <工具>` |
